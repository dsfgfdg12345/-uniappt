# 【最新版】沃德代驾源码全开源+前端uniapp

源码地址：ym7k.com/17894/

【最新版】沃德代驾是一套完整开源的代驾服务系统，采用 FastAdmin 后端搭配 UniApp 前端开发，整套源码无加密，支持私有化部署，覆盖用户端小程序、司机端、平台管理后台三大端口，围绕酒后代驾、商务代驾等主流场景搭建完整线上服务流程，解决传统代驾行业接单零散、调度低效、计费混乱、安全管控薄弱等痛点，适合本地代驾团队、代驾公司快速搭建属于自己的独立代驾运营平台。

<img width="426" height="929" alt="47b27f2de4f4059b59daa8cbb90b80d2" src="https://github.com/user-attachments/assets/5f9259ae-c0ca-415f-89ba-d4d9ce8df517" />

面向普通用户的小程序端主打轻量化下单体验，用户无需下载应用，微信内即可一键呼叫代驾。系统自动定位起点，用户填写目的地后，平台依据预设计价规则自动预估费用，支持即时叫车与预约代驾两种模式，满足临时代驾和提前规划的不同需求。下单之后，系统会推送附近在线司机，用户可实时查看司机位置、预计到达时间，全程追踪行驶轨迹。订单状态清晰区分待接单、已接单、行程中、已完成、已取消，消息实时推送提醒。行程内支持司乘在线沟通，平台启用隐私号码保护，隐藏双方真实手机号。系统内置安全模块，支持添加紧急联系人、行程录音留存，进一步降低出行风险。行程结束后支持线上支付，同时提供订单评价、开票申请功能，用户可以查看全部历史订单，方便对账与售后。

<img width="425" height="865" alt="243ef4dc31465019af2b3e79e1e9dc33" src="https://github.com/user-attachments/assets/5289fb8b-cfbe-42fb-a2da-db63ebf6ac70" />

司机端面向代驾师傅打造接单与收益管理体系，司机入驻需要提交身份与驾驶证信息，经过平台审核、实名认证之后才可开启接单。接单大厅实时刷新附近订单，支持抢单模式，收到新订单时消息提醒，避免漏单。接单成功后自动规划导航路线，引导司机快速抵达上车点。行程过程自动记录轨迹，服务完成后自动结算费用。司机个人中心可以查看每日订单、累计收入、提现记录，清晰掌握营收情况，同时可查看用户给出的评价，及时调整服务方式。司机可自主设置在线或者休息状态，灵活安排接单时间。

基于 FastAdmin 搭建的平台总后台，是整个系统的管控核心，拥有全面的运营配置能力。管理员负责司机资质审核，统一管理司机账号，管控司机上线权限。后台支持自定义多元化计价方案，可设置基础里程费、时长费、等候费、夜间溢价、返程费用，还能借助电子围栏划分不同区域定价，适配不同城市的收费标准。订单管理模块集中处理全部订单，可查看行程轨迹、录音记录，处理投诉与纠纷。平台自带营销工具，能够发放优惠券吸引新用户、激活老客户。数据看板直观展示订单总量、流水营收、司机接单量、用户增长等统计报表，为运营决策提供依据。后台精细化划分账号权限，区分超级管理员、运营人员等角色，保障业务数据安全。

得益于 UniApp 前端特性，前端适配微信小程序，源码全开源的特性给二次开发留下充足空间，运营者可根据自身业务需求修改页面、拓展功能。整套系统打通下单、派单、行程、支付、评价、售后的业务闭环，摆脱第三方代驾平台抽成与数据限制。借助这套系统，本地代驾团队能够自主掌握客户资源，规范服务流程；车主也能获得价格透明、轨迹可查、安全有保障的代驾服务，是本地代驾行业低成本数字化转型的成熟方案。
